# Mines, Grenades, Small Arms, Mortars, and Rockets — TM 21-210 (Sections II–IV)

## Section II — Mines and Grenades

Improvised mines, grenades, and shaped charges. Each item gives material required, procedure, and how to use; step-by-step procedures are in `references/full-text.md` only.

| Item | What it is |
|---|---|
| Pipe hand grenade | Pipe-body fragmentation grenade with a blasting-cap fuze |
| Nail grenade | Grenade body packed with nails as fragmentation |
| Wine bottle cone charge | Shaped charge using a wine bottle as the cone-liner form |
| Grenade–tin can land mine | Grenade rigged in a tin can as a pressure or trip device |
| Mortar scrap mine | Mine using mortar shell scrap |
| Coke bottle shaped charge | Shaped charge in a soft-drink bottle |
| Cylindrical cavity shaped charge | Shaped charge with a cylindrical cavity liner |
| Funnel shaped charge | Shaped charge using a funnel as the liner |
| Linear shaped charge | Line-shaped charge for cutting |

**Doctrine:** all items combine a container, an explosive filler from Section I, a fragmentation or liner element, and a fuze or firing device from Section VI. The shaped-charge items exploit the Munroe effect — a lined cavity that focuses explosive energy into a jet — using bottles, funnels, and cylinders as expedient liners.

## Section IV — Mortars and Rockets

Improvised indirect-fire weapons, pairing improvised launch tubes with Section I propellants and Section II/V grenades and incendiaries.

| Item | Notes |
|---|---|
| Recoilless launcher | Launcher for improvised rockets or grenades |
| Shotgun grenade launcher | Shotgun-based grenade launcher |
| Grenade launcher (57-mm cardboard container) | Launcher built from a 57-mm ammunition cardboard container |
| Fire bottle launcher | Launcher for incendiary fire bottles |
| Grenade launchers | Additional launcher variants |
| 80-mm mortar projectile launcher | Mortar tube and projectile with a range table |

**80-mm mortar range table:** the manual's only tabulated firing data for an improvised weapon. Range is set by tube elevation and the number of propellant increments; the table gives desired range (yards), maximum height the mortar will reach, angle of elevation (measured from horizontal), and required charge (number of increments).
