## Interference — sources and fixes

| Source | Fix |
|---|---|
| Natural (lightning, static, solar) | Change frequency; wait out the disturbance; use a frequency above the noise |
| Manmade (generators, power lines, ignition) | Move the noise source or the antenna; increase separation |
| Poor equipment / operator error | Check battery, connectors, cables, settings — the most common cause |
| Frequency interference / intermodulation | Separate transmitters; clean and tighten connectors (corroded joints mix signals) |
| Unauthorized frequencies | Transmit only on assigned frequencies |
| Frequency reuse | Propagation changes can make distant nets interfere; change frequency |

Troubleshooting order: power/battery → antenna and connections → frequency and mode → siting → interference. Move the antenna before adding power.

## Unusual environments — quick table

| Environment | Main problem | Countermeasure |
|---|---|---|
| Desert | Dust, heat, dry ground, static | Cover equipment; clean connectors daily; wet ground rods; shade batteries; ground yourself |
| Jungle | Vegetation absorbs VHF/UHF; humidity corrodes | HF ground wave; antenna above canopy; dry equipment daily |
| Cold | Batteries lose capacity; metal brittle; ice detunes antennas | Keep batteries warm; carry spares; clear ice; counterpoise wires on frozen ground |
| Mountains | Terrain blocks line of sight | Height + retransmission station on a peak |
| Urban | Buildings block and reflect | Rooftop siting; retrans |
| Sea | — | Salt water is an excellent ground-wave conductor; HF goes far over water |

## Electronic warfare

| Element | Meaning | Key techniques |
|---|---|---|
| Electronic attack (EA) | Deny the enemy the spectrum | Jamming, imitative deception (false traffic), manipulative deception, destruction |
| Electronic protection (EP) | Protect your own use | Frequency hopping, low power, short transmissions, directional antennas, EMCON, good procedure |
| Electronic warfare support (ES) | Find and locate enemy emissions | Direction finding, intercept |

Assume every transmission is intercepted and located. A net that transmits continuously, at high power, from a fixed location will be found, jammed, and targeted.

**Anti-jam checklist:** confirm it is jamming (check another frequency/radio) → reduce power → move antenna / change polarization → switch to alternate frequency or net → switch to frequency-hopping mode → directional antenna → shorten transmissions, use brevity codes → fall back to alternate means (messenger, wire, visual) and report.

## Phonetic numerals (Appendix E)

Say numbers digit by digit: 0 "zero", 1 "wun", 2 "too", 3 "tree", 4 "fower", 5 "fife", 6 "six", 7 "seven", 8 "ait", 9 "niner". Say "decimal" for a decimal point, "minus" for negative.

## Prowords (Appendix C) — the essential set

| Proword | Meaning |
|---|---|
| OVER | Transmission ended; response expected |
| OUT | Transmission ended; no response expected |
| ROGER | Received satisfactorily (not "yes" or "will comply") |
| WILCO | Received, understood, will comply |
| SAY AGAIN | Repeat your last transmission |
| I SAY AGAIN | I am repeating |
| CORRECTION | Error made; correct version follows |
| WAIT / WAIT OUT | Pause (seconds / longer); do not transmit |
| BREAK | Separating portions of a message |
| I SPELL | Next word spelled phonetically |
| FIGURES | Numbers follow |
| MESSAGE | A message follows |
| READ BACK | Repeat this entire transmission back exactly |
| WRONG | Your last transmission was incorrect |
| DISREGARD THIS TRANSMISSION | Cancel it |
| AUTHENTICATE | Challenge/response authentication required |
| RADIO CHECK | Requesting signal report (reply: readability + strength, e.g. "Lima Charlie") |
| SILENCE / SILENCE LIFTED | Cease / resume transmissions (net control station) |

Never say "over and out" — it is a contradiction.

## Calling procedure

"Alpha Two, this is Alpha One, over." Answer: "Alpha One, this is Alpha Two, over." The net control station controls the net; stations transmit only when called or when they have traffic. If two stations transmit at once, both are garbled — wait and try again.

## Field message format (Appendix G)

- Use BLOCK CAPITAL letters for all entries except the signature.
- Assign precedence and classification from the table.
- FROM block: originating organization. TO block: addressee(s).
- Date-time group is for communications personnel only.
- Draft briefly but clearly; the drafter is responsible for clarity.
- Classified messages go by secure voice or encrypted means only — never in the clear.

## Authentication (Appendix J) and the radio log (Appendix H)

- Authenticate with challenge-and-response from the authentication tables when a station is unknown, a message is suspicious, or when directed. Never reuse a challenge; never reveal the tables.
- Keep a radio log of every transmission: time, stations, traffic summary. It resolves disputes and supports debriefing. A log written from memory hours later is unreliable.

## Operator's pre-transmission checklist (Appendix P)

- [ ] Battery charged; spare carried
- [ ] Antenna correct, intact, connected
- [ ] Frequency, mode, hopset verified against the comms plan
- [ ] Time synchronized (required for frequency hopping)
- [ ] Call signs and prowords known
- [ ] Message blanks and log ready
- [ ] Ground connected; siting checked for line of sight
